# 🌐 ChatGPT Chat Exporter — Онлайн-версия с доступом из любой точки мира

В этой папке собрано готовое решение, которое можно загрузить на **GitHub** и получить доступ к экспорту чатов ChatGPT **с любого устройства (смартфона, планшета, рабочего ПК) вне дома**.

---

## 💡 Как это работает и какой способ выбрать?

Есть два самых удобных и 100% бесплатных варианта:

| Вариант | Что это дает | Сложность настройки |
|---|---|---|
| **Способ 1: Свой сайт через Vercel** *(Рекомендуется)* | Полноценный красивый веб-сайт с постоянным адресом `https://ваш-проект.vercel.app`, открывается в браузере на телефоне и компьютере. | 1 минута (3 клика мыши) |
| **Способ 2: GitHub Actions** *(Без сторонних сервисов)* | Выгрузка запускается прямо внутри GitHub на вкладке «Actions», готовый `.txt` сохраняется прямо в репозиторий. | 0 минут (уже настроено) |
| **Способ 3: Render / Hugging Face** | Альтернативный бесплатный облачный хостинг для веб-сервера. | 2 минуты |

---

## 🚀 Способ 1. Полноценный сайт через GitHub + Vercel (Рекомендуется)

Vercel — это бесплатная облачная платформа, которая идеально интегрируется с GitHub. При каждом изменении в репозитории она сама обновляет ваш сайт.

### Шаг 1. Загрузите эту папку на GitHub
1. Перейдите на [github.com](https://github.com) и создайте новый репозиторий (например, `chatgpt-exporter-web`).
2. В терминале на компьютере перейдите в эту папку и выполните команды:
   ```bash
   cd "chatgpt-exporter-web"
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/chatgpt-exporter-web.git
   git push -u origin main
   ```

### Шаг 2. Подключите Vercel (бесплатно)
1. Перейдите на [vercel.com](https://vercel.com) и войдите через свой аккаунт **GitHub**.
2. Нажмите синюю кнопку **«Add New...»** ➔ **«Project»**.
3. В списке репозиториев найдите ваш `chatgpt-exporter-web` и нажмите **«Import»**.
4. Никакие настройки менять не нужно (все параметры уже прописаны в `vercel.json`). Просто нажмите **«Deploy»**.
5. Через 30 секунд вы получите ссылку вида:
   👉 **`https://chatgpt-exporter-web.vercel.app`**

Теперь этот сайт доступен вам и вашим друзьям **с любого телефона и компьютера в мире 24/7**!

## 🤖 Способ 2. Экспорт прямо на GitHub через GitHub Actions (Без серверов)

Если вам не нужен отдельный сайт, а нужно лишь выгружать чаты вне дома:

1. Загрузите файлы на GitHub (как описано в Шаге 1 выше).
2. Откройте ваш репозиторий на GitHub в браузере (можно даже с телефона).
3. Перейдите во вкладку **Actions** сверху.
4. В левом меню нажмите на **«Экспорт чата ChatGPT»**.
5. Справа нажмите кнопку **«Run workflow»**:
   - Вставьте ссылку на чат ChatGPT (например, `https://chatgpt.com/share/...`).
   - Нажмите зеленую кнопку **«Run workflow»**.
6. Через 5-10 секунд задача завершится:
   - Файл `.txt` автоматически сохранится прямо в ваш репозиторий в папку **`exports/`** (вы сможете открыть и скачать его прямо на GitHub).
   - Также файл можно скачать внизу страницы выполнения в блоке **Artifacts**.

## 🐳 Способ 3. Деплой на Render.com или Hugging Face Spaces

Если вы предпочитаете Docker или сервис Render:

### На Render:
1. Зарегистрируйтесь на [render.com](https://render.com) (через GitHub).
2. Нажмите **New +** ➔ **Web Service**.
3. Выберите ваш репозиторий.
4. В поле **Runtime** укажите `Python 3`, в поле **Start Command** укажите `python3 app.py`.
5. Нажмите **Create Web Service** — сервис запустится и выдаст публичный URL `https://...onrender.com`.

### На Hugging Face Spaces:
1. Создайте Space на [huggingface.co/spaces](https://huggingface.co/spaces).
2. Выберите тип **Docker** (в репозитории уже есть готовый `Dockerfile`).
3. Загрузите файлы — сайт развернется автоматически.

## 💻 Локальный запуск и тестирование перед загрузкой

Чтобы проверить работу веб-интерфейса прямо на компьютере:

```bash
# Запуск автономного сервера:
python3 app.py --open
```
*Сервер запустится на `http://localhost:8080` и автоматически откроет страницу в браузере.*

## 📁 Структура файлов в этой папке

- **`public/`** — Фронтенд (веб-интерфейс):
  - `index.html` — современная страница с поддержкой мобильных устройств.
  - `style.css` — стили и темная тема.
  - `app.js` — логика интерфейса, генерация и скачивание `.txt` файлов.
- **`api/index.py`** — Бессерверный обработчик (Serverless API) для Vercel.
- **`app.py`** — Автономный сервер для локального использования или облачного хостинга (Render/Railway).
- **`chat_exporter.py`** — Ядро парсера и десериализатора ChatGPT TurboStream.
- **`vercel.json`** — Файл конфигурации маршрутизации для мгновенного деплоя на Vercel.
- **`Dockerfile`** — Контейнер для облачных платформ.
- **`.github/workflows/export-bot.yml`** — Сценарий GitHub Actions для выгрузки диалогов прямо внутри GitHub.
